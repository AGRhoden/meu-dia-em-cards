# Graças do Dia

Diário simples: cinco cards por dia (uma coisa boa, uma descoberta, uma ação muito boa, um acontecimento relevante e um card livre), calendário, diário contínuo com fotos e compartilhamento com a família.

App estático (HTML, CSS e JavaScript, sem build). Os dados ficam no aparelho e, com login Google, sincronizam pelo Supabase.

## Versões

- **1.0** — versão piloto: cinco cards por dia, calendário, diário com fotos, login Google, família por código de convite, backup semanal.
- **1.1** — os dias dos outros aparecem só em "Família"; o card livre pode ser publicado na família ou guardado só para quem escreveu; texto de boas-vindas.
